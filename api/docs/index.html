Authentication

Three ways to authenticate, depending on the endpoint:

  • Session token — returned by register/login, valid 30 days. Send Authorization: Bearer <token>. Best for the dashboard and personal scripts.
  • API key — lm_…, created in the dashboard under API keys or in the app. Send it as Authorization: Bearer lm_… or X-API-Key: lm_…. Keys share your account's quotas.
  • Private key — a fixed Bearer key for POST /api/v2/obfuscate only. No daily quota and a 1M-character limit.

The full API key is shown once at creation. LimeVM stores only a hash, so a lost key cannot be recovered — revoke it and make a new one.

Examples

Log in and read your profile

auth.sh
TOKEN=$(curl -s -X POST https://purrguy.pythonanywhere.com/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"you","password":"secret"}' | jq -r .token)

curl -s https://purrguy.pythonanywhere.com/api/auth/me \
  -H "Authorization: Bearer $TOKEN"
# → {"ok":true,"username":"you","tier":"free","tier_expires":0,
#    "discord_id":null,"discord_name":""}

Obfuscate with an API key

obfuscate.sh
curl -s -X POST https://purrguy.pythonanywhere.com/api/web-obfuscate \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source":"print(40 + 2)"}'
# → {"ok":true,"seed":123,"output":"-- limevm v2 …","strings":1,
#    "left_today":1,"unlimited":false}

A JSON body is always returned. unlimited is true for Lifetime accounts, which also report left_today: -1.

Upload a script and get a short link

upload.sh
curl -s -X POST https://purrguy.pythonanywhere.com/api/scripts \
  -H "X-API-Key: lm_YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"source":"print(1)","title":"demo"}'
# → {"ok":true,"slug":"AB12CD",
#    "url":"https://lime.purrguy.me/s/AB12CD",
#    "loadstring":"loadstring(game:HttpGet(\"…\"))()",
#    "duplicate":false}

List, then delete a link

manage.sh
curl -s https://purrguy.pythonanywhere.com/api/scripts \
  -H "X-API-Key: lm_YOUR_KEY"
curl -s -X DELETE https://purrguy.pythonanywhere.com/api/scripts/AB12CD \
  -H "X-API-Key: lm_YOUR_KEY"

Manage API keys

keys.sh
curl -s -X POST https://purrguy.pythonanywhere.com/api/keys \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"name":"my bot"}'
# → {"ok":true,"id":"…","api_key":"lm_…"}   ← shown once

curl -s -X DELETE https://purrguy.pythonanywhere.com/api/keys/KEY_ID \
  -H "Authorization: Bearer $TOKEN"

Private API (v2)

A dedicated endpoint for trusted integrations. One fixed Bearer key, no daily quota, up to 1,000,000 characters per call. Requests are audited in a private Discord channel (string count, account, masked key, time, IP).

private.sh
# plain text in → plain text out
curl -s -X POST https://lime.purrguy.me/api/v2/obfuscate \
  -H "Authorization: Bearer $LIMEVM_API_KEY" \
  --data-binary @script.lua -o out.lua

# JSON body
curl -s -X POST https://lime.purrguy.me/api/v2/obfuscate \
  -H "Authorization: Bearer $LIMEVM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"source":"print(1)","seed":123}'
# → {"ok":true,"seed":123,"output":"-- limevm v2 …","in_chars":8,
#    "out_chars":…,"strings":1}

Add ?raw=1 to force a plain-text response. CORS is open. Send the key in Authorization: Bearer …; anything else returns 401.

Running hosted scripts

Short links return raw Lua, so any executor can fetch and run them:

fetch.lua
loadstring(game:HttpGet("https://lime.purrguy.me/s/SLUG"))()

Fetching a link needs no authentication. Uploading, deleting and every obfuscation endpoint do.
