Getting started

  1. Make an account. Use the Log in button on the homepage or register inside the app. Username is 3–20 characters (letters, numbers, _, -); password is 6+ characters.
  2. Log in. The same account works on the website dashboard, the Windows app and the HTTP API.
  3. Obfuscate. Paste Lua/Luau in the dashboard, use the Windows app, or call the API.
  4. Run the output exactly like the original script. Behaviour is expected to be identical.

Free accounts can obfuscate scripts up to 3,000 characters and use the dashboard obfuscator 2 times per day (up to 300,000 characters). Paid plans raise these limits.

Using the dashboard

The dashboard is the fastest way to obfuscate without installing anything. Tabs:

  • Overview — account status, plan, recent activity and changelog.
  • Obfuscator — paste or load a .lua/.luau file, then hit Obfuscate. You can save inputs locally, download the result, or upload it as a short link. A normal squeeze is a few seconds.
  • History — your recent squeezes with input/output size, seed and tier.
  • API keys — create keys for scripts and bots. The full key is shown once; only a hash is stored. Revoke a key at any time.
  • Plans — current pricing and what each tier unlocks.

Desktop app

The Windows app is a single executable (~13 MB), no installer. It includes the same engine, local script history, themes and Discord login.

  • Download from the download page or the Discord server.
  • Obfuscation works offline; license checks tolerate up to 14 days without internet.
  • Updates are announced in Discord and on the changelog.

Script links

Upload any script and LimeVM returns a short URL such as https://lime.purrguy.me/s/AB12CD. Run it in an executor with:

loadstring
loadstring(game:HttpGet("https://lime.purrguy.me/s/AB12CD"))()
  • Free accounts: 3 uploads/day, links expire after 5 days.
  • Paid accounts: 20 uploads/day, links never expire.
  • Uploading the same script twice returns the existing link instead of a duplicate.

Troubleshooting

“unauthorized” / logged out

Sessions last 30 days and are invalidated on logout. Log in again. API keys can be revoked in the dashboard; create a fresh one if a key stops working.

“daily-used”

You hit the daily quota. Quotas reset at midnight UTC. Lifetime accounts have no daily cap.

“too-big”

Free tier caps at 3,000 characters. The dashboard accepts up to 300,000; the private API accepts up to 1,000,000.

Obfuscated script errors

First run the original in the same executor. If the original works and the output does not, report it in Discord with both versions and the seed from History.

Plan not showing

The plan is attached to your LimeVM account. Make sure Discord is linked, then reload the dashboard or the app. Staff can check the account in a ticket.

Large scripts

Huge inputs take longer and produce larger output (roughly 4–5× the source). The engine handles 200 KB+ Luau scripts; use the private API for the biggest jobs.

Still stuck? Ask in the Discord server — include the error text, input size and seed.
